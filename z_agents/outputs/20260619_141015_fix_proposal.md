# Proposition de correction — Broadcasts dans transactions + race condition hunter_pending + round guard ProcessSeerTurn

## Résumé
- **Bugs corrigés :**
  1. Broadcasts et `notify()` à l'intérieur de `DB::transaction()` + `lockForUpdate()` dans `GameService` (`cancelGame`, `markReady`, `joinGame`, `startGame`, `excludePlayer`) — risque de deadlock MySQL si Reverb est lent.
  2. Lecture + suppression de `hunter_pending` sans atomicité dans `ProcessNightEnd` — risque de double dispatch de `ProcessHunterTurn` avec workers concurrents.
  3. `ProcessSeerTurn` sans paramètre `$round` — incohérence avec les autres jobs, risque de double broadcast `SeerTurnStarted` sur retry Laravel.
- **Fichiers modifiés :** `app/Services/GameService.php`, `app/Jobs/ProcessNightEnd.php`, `app/Jobs/ProcessSeerTurn.php`
- **Fichiers additionnels requis :** `app/Jobs/ProcessMayorElection.php`, `app/Services/PhaseManager.php` (call sites du constructeur modifié — total : 5 fichiers, dans la limite autorisée)

---

## Modifications détaillées

### Fichier : `app/Services/GameService.php`

#### 1. `cancelGame()` — broadcast sorti de la transaction

**Avant :**
```php
public function cancelGame(Game $game): void
{
    DB::transaction(function () use ($game) {
        $locked = Game::where('id', $game->id)
            ->whereNotIn('status', ['finished', 'waiting'])
            ->lockForUpdate()
            ->first();

        if (! $locked) {
            return;
        }

        $locked->update([
            'status'      => 'finished',
            'winner_team' => null,
            'finished_at' => now(),
        ]);

        $players = $locked->players()->get();

        broadcast(new GameFinished($locked, $players, null));
    });
}
```

**Après :**
```php
public function cancelGame(Game $game): void
{
    $result = DB::transaction(function () use ($game) {
        $locked = Game::where('id', $game->id)
            ->whereNotIn('status', ['finished', 'waiting'])
            ->lockForUpdate()
            ->first();

        if (! $locked) {
            return null;
        }

        $locked->update([
            'status'      => 'finished',
            'winner_team' => null,
            'finished_at' => now(),
        ]);

        return ['game' => $locked, 'players' => $locked->players()->get()];
    });

    if ($result) {
        broadcast(new GameFinished($result['game'], $result['players'], null));
    }
}
```

**Raison :** Le broadcast tenait le lock MySQL exclusif sur `games` pendant toute la durée de l'I/O réseau vers Reverb. Tout autre job tentant un `lockForUpdate` sur la même ligne attendait jusqu'à l'expiration.

#### 2. `markReady()` — broadcasts sortis de la transaction

**Avant :**
```php
public function markReady(GamePlayer $player): void
{
    DB::transaction(function () use ($player) {
        $game = Game::where('id', $player->game_id)
            ->where('status', 'electing_mayor')
            ->lockForUpdate()
            ->first();

        if (! $game || $player->is_ready) {
            return;
        }

        $player->update(['is_ready' => true]);

        $total      = $game->players()->count();
        $readyCount = $game->players()->where('is_ready', true)->count();

        broadcast(new PlayerReady($game, $readyCount, $total));

        if ($readyCount === $total && $game->phase_deadline === null) {
            $timer    = $game->timer('mayor_election');
            $deadline = now()->addSeconds($timer);
            $game->update(['phase_deadline' => $deadline]);
            broadcast(new MayorElectionStarted($game));
            ProcessMayorElection::dispatch($game->id)->delay(now()->addSeconds($timer));
        }
    });
}
```

**Après :**
```php
public function markReady(GamePlayer $player): void
{
    $result = DB::transaction(function () use ($player) {
        $game = Game::where('id', $player->game_id)
            ->where('status', 'electing_mayor')
            ->lockForUpdate()
            ->first();

        if (! $game || $player->is_ready) {
            return null;
        }

        $player->update(['is_ready' => true]);

        $total      = $game->players()->count();
        $readyCount = $game->players()->where('is_ready', true)->count();

        $startElection = false;
        if ($readyCount === $total && $game->phase_deadline === null) {
            $timer = $game->timer('mayor_election');
            $game->update(['phase_deadline' => now()->addSeconds($timer)]);
            ProcessMayorElection::dispatch($game->id)->delay(now()->addSeconds($timer));
            $startElection = true;
        }

        return compact('game', 'readyCount', 'total', 'startElection');
    });

    if ($result) {
        broadcast(new PlayerReady($result['game'], $result['readyCount'], $result['total']));
        if ($result['startElection']) {
            broadcast(new MayorElectionStarted($result['game']));
        }
    }
}
```

**Raison :** Les deux broadcasts sont retirés de la transaction lockForUpdate. Le dispatch de `ProcessMayorElection` reste dans la transaction — delay > 0, autorisé par les règles.

#### 3. `joinGame()` — broadcast et startGame() sortis de la transaction

**Avant :**
```php
public function joinGame(User $user, string $code, string $pseudo): GamePlayer
{
    return DB::transaction(function () use ($user, $code, $pseudo) {
        $game = Game::where('code', $code)->lockForUpdate()->first();

        // ... guards ...

        $player = GamePlayer::create([
            'game_id'   => $game->id,
            'user_id'   => $user->id,
            'pseudo'    => $pseudo,
            'joined_at' => now(),
        ]);

        broadcast(new PlayerJoined($game, $player));

        $currentCount = $game->players()->count();
        if ($currentCount === $game->max_players) {
            $this->startGame($game);
        }

        return $player;
    });
}
```

**Après :**
```php
public function joinGame(User $user, string $code, string $pseudo): GamePlayer
{
    $result = DB::transaction(function () use ($user, $code, $pseudo) {
        $game = Game::where('code', $code)->lockForUpdate()->first();

        if (! $game) {
            abort(404, 'Partie introuvable.');
        }

        if ($game->status !== 'waiting') {
            abort(409, 'Cette partie a déjà commencé.');
        }

        $existing = GamePlayer::where('game_id', $game->id)
            ->where('user_id', $user->id)
            ->first();

        if ($existing) {
            return ['player' => $existing, 'broadcast' => false, 'start' => false, 'game' => null];
        }

        if ($game->players()->count() >= $game->max_players) {
            abort(409, 'Cette partie est déjà complète.');
        }

        $excluded = Exclusion::where('game_id', $game->id)
            ->where('user_id', $user->id)
            ->exists();

        if ($excluded) {
            abort(403, 'Tu as été exclu de cette partie.');
        }

        $player = GamePlayer::create([
            'game_id'   => $game->id,
            'user_id'   => $user->id,
            'pseudo'    => $pseudo,
            'joined_at' => now(),
        ]);

        $currentCount = $game->players()->count();
        $shouldStart  = ($currentCount === $game->max_players);

        return ['player' => $player, 'broadcast' => true, 'start' => $shouldStart, 'game' => $game];
    });

    if ($result['broadcast']) {
        broadcast(new PlayerJoined($result['game'], $result['player']));
    }

    if ($result['start']) {
        $this->startGame($result['game']);
    }

    return $result['player'];
}
```

**Raison :** Le broadcast `PlayerJoined` et l'appel à `startGame()` (qui contient ses propres broadcasts) sont retirés de la transaction lockForUpdate. La transaction ne contient plus que les écritures DB. `startGame()` s'exécute après que le lock de `joinGame` est libéré, dans sa propre transaction indépendante — `startGame()` re-verrouille de toute façon avec son propre `lockForUpdate`.

#### 4. `startGame()` — broadcasts et notify() sortis de la transaction

**Avant :**
```php
public function startGame(Game $game): void
{
    DB::transaction(function () use ($game) {
        $locked = Game::where('id', $game->id)
            ->where('status', 'waiting')
            ->lockForUpdate()
            ->first();

        if (! $locked) {
            return;
        }

        if (! $locked->canTransition('start_election')) {
            Log::warning("Transition 'start_election' refusée depuis status={$locked->status}");
            return;
        }

        $locked->update([
            'status'      => 'electing_mayor',
            'started_at'  => now(),
            'timers'      => TimerCalculator::forPlayerCount($locked->max_players),
        ]);

        $players     = $locked->players()->get();
        $assignments = $this->roleDistributor->distribute($players, $locked);

        foreach ($assignments as $playerId => $role) {
            GamePlayer::where('id', $playerId)->update(['role' => $role]);
        }

        $players = $locked->players()->with('user')->get();

        broadcast(new GameStarted($locked));

        foreach ($players as $player) {
            $allies = null;
            if ($player->isWerewolf()) {
                $allies = $players
                    ->filter(fn (GamePlayer $p) => $p->id !== $player->id && $p->isWerewolf())
                    ->map(fn (GamePlayer $p) => ['id' => $p->id, 'pseudo' => $p->pseudo])
                    ->values()
                    ->toArray();
            }

            broadcast(new GameStarted($locked, $player, $allies));

            try {
                $player->user->notify(new RoleAssignedNotification($player->role));
            } catch (\Throwable) {}
        }

        WaitForReadyPlayers::dispatch($locked->id)->delay(
            now()->addSeconds($locked->timer('ready_timeout'))
        );
    });
}
```

**Après :**
```php
public function startGame(Game $game): void
{
    $data = DB::transaction(function () use ($game) {
        $locked = Game::where('id', $game->id)
            ->where('status', 'waiting')
            ->lockForUpdate()
            ->first();

        if (! $locked) {
            return null;
        }

        if (! $locked->canTransition('start_election')) {
            Log::warning("Transition 'start_election' refusée depuis status={$locked->status}");
            return null;
        }

        $locked->update([
            'status'      => 'electing_mayor',
            'started_at'  => now(),
            'timers'      => TimerCalculator::forPlayerCount($locked->max_players),
        ]);

        $players     = $locked->players()->get();
        $assignments = $this->roleDistributor->distribute($players, $locked);

        foreach ($assignments as $playerId => $role) {
            GamePlayer::where('id', $playerId)->update(['role' => $role]);
        }

        WaitForReadyPlayers::dispatch($locked->id)->delay(
            now()->addSeconds($locked->timer('ready_timeout'))
        );

        return ['game' => $locked, 'players' => $locked->players()->with('user')->get()];
    });

    if (! $data) {
        return;
    }

    $locked  = $data['game'];
    $players = $data['players'];

    broadcast(new GameStarted($locked));

    foreach ($players as $player) {
        $allies = null;
        if ($player->isWerewolf()) {
            $allies = $players
                ->filter(fn (GamePlayer $p) => $p->id !== $player->id && $p->isWerewolf())
                ->map(fn (GamePlayer $p) => ['id' => $p->id, 'pseudo' => $p->pseudo])
                ->values()
                ->toArray();
        }

        broadcast(new GameStarted($locked, $player, $allies));

        try {
            $player->user->notify(new RoleAssignedNotification($player->role));
        } catch (\Throwable) {}
    }
}
```

**Raison :** Tous les broadcasts et `notify()` déplacés après la transaction. Le rechargement `with('user')` est déplacé juste avant le `return` dans la transaction pour que les données soient prêtes après commit. Le dispatch de `WaitForReadyPlayers` reste dans la transaction (delay = `ready_timeout` > 0, autorisé).

#### 5. `excludePlayer()` — broadcasts et notify() sortis de la transaction

**Avant :**
```php
DB::transaction(function () use ($game, $target, $reason) {
    $targetUser = $target->user;

    Exclusion::create([
        'game_id'     => $game->id,
        'user_id'     => $targetUser->id,
        'player_id'   => $target->id,
        'reason'      => $reason,
        'excluded_at' => now(),
    ]);

    $target->delete();

    broadcast(new PlayerExcluded($game, $target));
    broadcast(new PlayerExcluded($game, $target, $reason));

    try {
        $targetUser->notify(new PlayerExcludedNotification($reason));
    } catch (\Throwable) {}
});
```

**Après :**
```php
$targetUser = $target->user;

DB::transaction(function () use ($game, $target, $reason, $targetUser) {
    Exclusion::create([
        'game_id'     => $game->id,
        'user_id'     => $targetUser->id,
        'player_id'   => $target->id,
        'reason'      => $reason,
        'excluded_at' => now(),
    ]);

    $target->delete();
});

broadcast(new PlayerExcluded($game, $target));
broadcast(new PlayerExcluded($game, $target, $reason));

try {
    $targetUser->notify(new PlayerExcludedNotification($reason));
} catch (\Throwable) {}
```

**Raison :** `$targetUser` est chargé avant la transaction (le `delete()` ne touche que `game_players`, pas `users`). Le commentaire existant "L'event stocke des scalaires : pas de dépendance DB après delete" confirme que les events `PlayerExcluded` sont safe à instancier après la suppression — les données du modèle `$target` restent en mémoire.

### Fichier : `app/Jobs/ProcessNightEnd.php`

**Avant :**
```php
$hunterPending = GameAction::where('game_id', $game->id)
    ->where('type', 'hunter_pending')
    ->where('round', $game->round)
    ->first();

if ($hunterPending) {
    $hunterPending->delete();
    ProcessHunterTurn::dispatch($game->id, $game->round, $hunterPending->player_id)->delay(0);
    return;
}
```

**Après :**
```php
$hunterId = DB::transaction(function () use ($game) {
    $hunterPending = GameAction::where('game_id', $game->id)
        ->where('type', 'hunter_pending')
        ->where('round', $game->round)
        ->lockForUpdate()
        ->first();

    if (! $hunterPending) {
        return null;
    }

    $playerId = $hunterPending->player_id;
    $hunterPending->delete();
    return $playerId;
});

if ($hunterId !== null) {
    ProcessHunterTurn::dispatch($game->id, $game->round, $hunterId)->delay(0);
    return;
}
```

Ajouter l'import manquant en tête du fichier :
```php
use Illuminate\Support\Facades\DB;
```

**Raison :** Le `lockForUpdate()` garantit qu'une seule instance de `ProcessNightEnd` peut lire et supprimer le record `hunter_pending` — la deuxième instance trouve `null` et poursuit vers `endNight()` (no-op car le statut aura déjà changé). Le dispatch reste hors transaction (`delay(0)` interdit dans une transaction selon les règles).

### Fichier : `app/Jobs/ProcessSeerTurn.php`

**Avant :**
```php
/**
 * @param int $gameId Identifiant de la partie.
 */
public function __construct(public readonly int $gameId) {}

/**
 * ...
 * Guards d'entrée :
 *   - La partie existe.
 *   - status === 'night'.
 * ...
 */
public function handle(): void
{
    $game = Game::find($this->gameId);

    if (! $game || $game->status !== 'night') {
        return;
    }
```

**Après :**
```php
/**
 * @param int $gameId Identifiant de la partie.
 * @param int $round  Round de référence (double-fire guard).
 */
public function __construct(
    public readonly int $gameId,
    public readonly int $round,
) {}

/**
 * ...
 * Guards d'entrée :
 *   - La partie existe.
 *   - round === $this->round.
 *   - status === 'night'.
 * ...
 */
public function handle(): void
{
    $game = Game::find($this->gameId);

    if (! $game || $game->status !== 'night' || $game->round !== $this->round) {
        return;
    }
```

**Raison :** Aligne `ProcessSeerTurn` sur le pattern établi par tous les autres jobs paramétrés (`ProcessNightEnd`, `ProcessWitchTurn`, etc. — cf. conformité #11 du rapport de détection). Sans ce guard, un retry Laravel sur une nuit ultérieure (même statut `'night'`) diffuserait `SeerTurnStarted` une seconde fois.

```php
ProcessSeerTurn::dispatch($this->gameId, $result['game']->round)
```

### Fichier additionnel requis : `app/Services/PhaseManager.php`

**Avant :**
```php
ProcessSeerTurn::dispatch($locked->id)
    ->delay(now()->addSeconds($locked->timer('night_start_delay')));
```

**Après :**
```php
ProcessSeerTurn::dispatch($locked->id, $locked->round)
```

## Remarques
- **Scope étendu :** Le rapport source listait 3 fichiers. `ProcessMayorElection.php` et `PhaseManager.php` sont requis pour que le fix `ProcessSeerTurn` soit compilable — total : 5 fichiers, dans la limite autorisée.
- **Bug [POTENTIEL] VoteService::castDayVote()** non inclus : il ne figurait pas dans la section "Fichiers concernés" du rapport source. À traiter dans un rapport dédié si la fenêtre de risque (~1-2 ms) est jugée suffisamment critique.
- **Docstring GameService (ligne 37)** mentionne encore "sauf dans startGame() où les broadcasts sont intégrés à la transaction" — cette phrase est obsolète après ce fix. Correction cosmétique à inclure dans le commit.
- Les `notify()` dans `startGame()` et `excludePlayer()` sont dans un `try/catch(\Throwable)` — les erreurs réseau sur les notifications push n'affectent pas la cohérence des données.
